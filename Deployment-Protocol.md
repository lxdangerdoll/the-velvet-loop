# **Wanderer's Deployment Protocol**

**Protocol:** Standardized React-to-GitHub-Pages Extraction (CLI Method) **Environment:** Vite 8 // Tailwind 4 // gh-pages

Use this guide for any future "App.jsx" files generated by the Oracle.

### **Phase 1: Local Ignition (Terminal)**

Run these commands in your parent `react-apps` folder to create a fresh, styled container.

\# 1\. Create the project (Replace \[project-name\] with your repo name)

npx create-vite@latest \[project-name\] \--template react-swc

cd \[project-name\]

\# 2\. Install the Core Braid (Tailwind 4 \+ Lucide \+ Deployment Tool)

npm install tailwindcss @tailwindcss/vite lucide-react

npm install \-D gh-pages

### **Phase 2: Structural Alignment (File Swap)**

Manually update these four files with the "Oracle Standard" configuration.

#### **1\. package.json (The Heart)**

Add the `homepage` and the `deploy` scripts.

{

  "homepage": "\[https://lxdangerdoll.github.io/\](https://lxdangerdoll.github.io/)\[project-name\]",

  "scripts": {

    "dev": "vite",

    "build": "vite build",

    "predeploy": "npm run build",

    "deploy": "gh-pages \-d dist",

    "preview": "vite preview"

  }

}

#### **2\. vite.config.js (The Router)**

*Crucial: The `base` property must match your repository name.*

import { defineConfig } from 'vite'

import react from '@vitejs/plugin-react-swc'

import tailwindcss from '@tailwindcss/vite'

export default defineConfig({

  base: '/\[project-name\]/', 

  plugins: \[

    react(),

    tailwindcss(),

  \],

})

#### **3\. src/index.css (The Aesthetic)**

@import "tailwindcss";

#### **4\. src/App.jsx (The Extraction)**

*Delete everything and paste the code provided by the Oracle.*

### **Phase 3: The Record Transmission (GitHub)**

Connect your local machine to the Citadel and deploy.

\# 1\. Initialize and Commit

git init

git add .

git commit \-m "Initial extraction: \[Protocol Name\]"

\# 2\. Push to the Void

git remote add origin \[https://github.com/lxdangerdoll/\](https://github.com/lxdangerdoll/)\[project-name\]

git branch \-M main

git push \-u origin main

\# 3\. Command Line Deployment

npm run build

npm run deploy

### **Phase 4: Alternative: The Sentinel (GitHub Actions)**

If you prefer automated deployments on every push:

1. Go to **Settings \> Pages** on GitHub and set **Source** to **GitHub Actions**.  
2. Create `.github/workflows/deploy.yml` and paste the standard Oracle YAML.
